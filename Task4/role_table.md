| Роль  | Права роли | Группы пользователей |
| --- | --- | --- |
| Название роли, которое отвечает требованиям RBAC в Kubernets. | Укажите права, которые необходимо выдать этой роли. | Выделите группы пользователей в организации, которые нужно связать с этой ролью. |
| admin | Полный доступ (включая управление ролями) | Главные инженеры по эксплуатации |
| editor | Настройки ресурсов всего кластера (включая управление секретами) | инженеры по эксплуатации |
| auditor | Просмотр ресурсов всего кластера | Специалист по ИБ |
| viewer | Просмотр неймспейсов всех доменов | Все разработчики и devops-инженеры |
| developer | Управление всеми неймспейсами для разработки и тестирования | Все разработчики |
| devops | Управление всеми продуктивными неймспейсами | Все девопсеры |
